# DevSecOps
Задание №2. Реализовать Web-приложение для дальнейшего использования в ходе курса обучения. Пример исходника вложением. Язык программирования - на ваш выбор. Способ доставки приложения на проверку - почтой (исходники) или github (иной сервис по работе с исходниками на ваш выбор) (файлообменники желательно не использовать). Критерии оценки - архитектура реализации (подключение к нескольким БД, REST для 4х видов запросов), запуск веб-приложения, возможность получить данные методом Get из данных, хранимых в памяти, отсутствие уязвимостей, определенных через SAST PT. Если приложение будете делать по аналогии с приложением курса, изменяйте предметную область и привносите что-то свое, иначе при полном копировании оценка будет снижаться.
